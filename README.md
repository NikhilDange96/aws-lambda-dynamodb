# Insert Data into DynamoDB using AWS Lambda

## Project Overview

This project demonstrates how to insert data into an Amazon DynamoDB table using an AWS Lambda function.

## AWS Services Used

- AWS Lambda
- Amazon DynamoDB
- AWS IAM

## Project Workflow

AWS Lambda
↓
Amazon DynamoDB
↓
Data Stored in DynamoDB

## What I Did

- Created a DynamoDB table
- Created an AWS Lambda function
- Configured IAM permissions
- Connected Lambda with DynamoDB
- Inserted data into DynamoDB
- Tested the Lambda function
